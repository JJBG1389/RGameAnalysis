# Changelog

## 5.3
- Added Contested Performance Retention (CPR).
- Added Capability Maturity Gates: Exists → Reliable → Integrated → Contested → Optimized.
- Incorporated lessons from cross-domain stress tests including combat robotics, Formula SAE, dynamic race strategy, and historical autonomous challenges.
- Elevated performance retention under disruption and completion/reliability before optimization.

## 5.2
- Added Team Execution Capacity (TEC) tranches T1–T6.
- Added season stages G1–G6.
- Added trajectory (rising/stable/declining).
- Changed recommendations from one universal optimum to Game × Tranche × Stage × Trajectory.

## 5.1
- Added tranche-aware development strategy concept.
- Formalized team execution capacity as a model input.

## 5.0
- Changed objective toward probability of event success.
- Formalized red-team opponent optimization.
- Added technology readiness, calendar/schedule risk, progressive fidelity, and Value of Information.
- Strengthened simplicity/Pareto frontier.

## 4.x
- Added reliability distributions, alliance co-optimization, qualification vs playoff objectives, counter-meta evolution, season compression, draft value, and development burden.
- Established that functional specification is a more reliable target than exact mechanism prediction.

## 3.x
- Added empirical season data, component contribution metrics, season-development curves, and Bayesian/live updating.
- Began using TBA/Statbotics/FTCScout/RobotEvents-style data rather than championship outcomes alone.

## 2.x
- Added field geometry, game-piece economy, opponent interaction, defense/denial, alliance specialization, and Worlds cycle-time compression.

## 1.x
- Initial rules-derived model emphasizing autonomous leverage, scoring throughput, cycle time, endgame ROI, reliability, and alliance specialization.

## Validation note
Historical percentage scores discussed during model development were structured retrospective similarity assessments, not calibrated probabilities. Model 5.3 adopts a stricter rolling-origin validation policy for future reproducible testing.
